# Milestones

- M0: reproducible Godot C# bootstrap, GitHub CI, H:-only intentional install/cache policy, actual Windows acceptance.
- M1: editable living world with zoom/pan, terrain tools, deterministic command stream and benchmarks.
- M2: life/ecology: animals, food, needs, reproduction, deaths and navigation.
- M3: settlements: village foundations, homes, resources, jobs.
- M4: kingdoms: factions, borders, rulers, diplomacy, wars.
- M5: god powers: fire, storms, disasters, diseases.
- M6: save/load, panels, minimap, reliability and performance.
- M7: original user-designed game mechanics and new identity.

Every milestone requires tested implementation, engineering notes and user review before merge.
